## Цель работы

Изучение методов сканирования Nmap, определения открытых портов,
сетевых сервисов и операционных систем, а также поиска уязвимостей
с помощью NSE.

## Выполненные задания

- Сканирование TCP-портов и определение версий сервисов.
- Обнаружение активных хостов и анализ сетевых интерфейсов.
- Использование TCP SYN, ACK и расширенных режимов Nmap.
- Проверка уязвимостей с помощью NSE.
- Экспорт результатов в текстовый, XML и HTML-форматы.
- Настройка прав доступа и POSIX ACL.
- Исключение конфиденциальных результатов из Git.

## Содержимое репозитория

- `README.md` - описание лабораторной работы.
- `exmp_targets.txt` - список разрешённых целей.
- `.gitignore` - исключение результатов сканирования.

## Безопасность

Сканирование проводилось на собственной виртуальной машине и
разрешённом учебном сервере scanme.nmap.org.

Результаты сканирования сохраняются локально и не публикуются
в открытом репозитории.
